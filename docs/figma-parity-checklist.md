## Aceite CMS (v1.10+)

1. Editar 1 campo Home no painel → salvar → conferir front.
2. Atualizar tema (bump Version) → o valor **permanece** (não volta ao default).
3. Editar strip CTA de uma especialidade → persiste após update.
4. Criar página com template **Especialidade** → aparece card no hub (ao salvar).
5. Reordenar seções Home no flexible → ordem refletida no front.
